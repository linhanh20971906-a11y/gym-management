# Hệ thống Quản lý Phòng Gym / Fitness

## Giới thiệu
Website quản lý hội viên, gói tập, lịch tập và huấn luyện viên.

## Công nghệ
- Node.js + Express
- HTML, CSS, JavaScript
- MySQL + phpMyAdmin
- Docker Compose
- Nginx Reverse Proxy
- Prometheus + Grafana
- Loki + Promtail

## Mục tiêu
Triển khai hệ thống quản lý Gym bằng Docker Compose,
tích hợp giám sát, logging và bảo mật.
